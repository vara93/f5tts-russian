# F5‑TTS Russian — локальная CPU-лаборатория

Законченное локальное приложение для сравнения русских референсов, ручных ударений и параметров F5‑TTS. Голос и текст остаются на сервере. Архитектура: Nginx `:80` → Gradio/FastAPI `127.0.0.1:7860` → русская `F5TTS_v1_Base_v2` и локальный Vocos. Авторизации нет: **не выставляйте сервер в интернет**.

## Установка

Только чистая Ubuntu Server 26.04 LTS amd64, минимум около 8 ГБ свободного места; рекомендуется 8–16 ГБ RAM. Системный Python не меняется: `uv` устанавливает CPython 3.11.13 в собственное хранилище и venv.

```bash
sudo bash install.sh
# Если UFW активен, открыть HTTP только локальной сети:
sudo bash install.sh --allow-cidr 10.0.0.0/8
```

Установщик до любых изменений прекращает работу, если порт 80 занят. Он скачивает адресно только русский checkpoint, vocabulary и два файла Vocos; публичные Gradio share-ссылки и аналитика отключены. После установки откройте `http://<IPv4-сервера>/`. Загрузка аудиофайла работает по HTTP; браузерный микрофон на HTTP/IP обычно ограничен политикой secure context, поэтому используйте HTTPS или загрузку файла.

## Эксплуатация и диагностика

```bash
systemctl status f5tts-russian
journalctl -u f5tts-russian -f
bash /opt/f5tts-russian/scripts/diagnose.sh
curl -f http://127.0.0.1:7860/healthz
curl -f http://127.0.0.1:7860/readyz
sudo systemctl restart f5tts-russian
```

`healthz` означает, что процесс отвечает; `readyz` возвращает HTTP 200 только после однократной загрузки модели и Vocos. Запросы синтеза выполняются строго по одному. Временные WAV имеют случайные имена, чистятся при старте и не журналируются вместе с пользовательским текстом.

## Обновление

Сначала обновите полные immutable-ревизии и версии в `config.py`, `pyproject.toml`, `install.sh` и `VERSIONS.md`, проверьте API, затем повторите `sudo bash install.sh`. Не переключайте вариант на v4 без отдельного теста русских ударений. Установка идемпотентна, но специально не выполняет автоматическое непроверенное обновление модели.

## Разработка и проверки

```bash
python3 -m compileall -q app.py engine.py config.py scripts tests
python3 -m pytest -q
bash -n install.sh scripts/diagnose.sh
```

CPU-синтез может быть существенно медленнее аудио. Выразительность в первую очередь задаётся манерой референса. Модель распространяется на условиях CC BY-NC 4.0 и предназначена для некоммерческого применения.
